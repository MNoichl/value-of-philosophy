Raw PhilPapers journal archive pages, saved from a browser (PhilPapers is behind Cloudflare and
blocks scripted access). Save https://philpapers.org/journals as "Webpage, HTML only" here as
`journals.html`; if the archive paginates, save each page as `journals_p1.html`, `journals_p2.html`, ...
`vop.philpapers` parses these into `inputs/philpapers_journals.csv`.
